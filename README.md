# Ikkashin School

A modern school management system built with React, Vite, and Tailwind CSS.

## Features

- **Student Management**: Add, view, and manage student records.
- **Admission Tracking**: Track student admissions and applications.
- **Staff Management**: Manage teacher and staff details.
- **Attendance**: Mark and monitor student attendance.
- **Fee Management**: Track fee payments and balances.
- **Results**: Enter and view student results.
- **Classroom Management**: Manage class schedules and assignments.
- **Timetable**: View school timetables.
- **Social Sharing**: Share school news and events via social media.
- **Modal System**: Reusable modal components for various actions.
- **Button Components**: Consistent button styling with variants.
- **Toast Notifications**: User feedback for actions like copying links.
- **Responsive Design**: Works seamlessly on different screen sizes.
